# Operating System Lab Assignment

This repository contains the **Operating System Laboratory Programs** completed as part of the Bachelor of Technology in Computer Science and Engineering curriculum at Doon University, Session 2026–2027.

The repository covers fundamental Operating System concepts through practical implementations using **Python and Linux/UNIX system programming concepts**.

## 📚 List of Experiments

| No. | Experiment | Concepts Covered |
|---|---|---|
| 1 | Process Creation using `fork()`, `exec()` and `wait()` | Linux System Calls, Process Management |
| 2 | Thread Creation using POSIX Threads | Multithreading, Thread Management |
| 3 | CPU Scheduling Algorithms | FCFS, SJF, Priority, Round Robin |
| 4 | Producer-Consumer Problem | Process Synchronization, Semaphores |
| 5 | Readers-Writers Problem | Synchronization, Mutual Exclusion |
| 6 | Dining Philosophers Problem | Semaphores, Deadlock Prevention |
| 7 | Banker's Algorithm | Deadlock Avoidance, Safe State |
| 8 | Contiguous Memory Allocation | First Fit, Best Fit, Worst Fit |
| 9 | Page Replacement Algorithms | FIFO, LRU, Optimal |
| 10 | Disk Scheduling Algorithms | FCFS, SSTF, SCAN, C-SCAN |
| 11 | File Allocation Methods | Contiguous, Linked, Indexed Allocation |

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Operating System:** Linux (Ubuntu-based, via Google Colab)
- **Interpreter:** CPython 3
- **Libraries:** `os`, `sys` (system calls), `threading` (threads and semaphores), `collections.deque`, `copy`, `warnings` (Python standard library only)
- **Development Environment:** Google Colab (Jupyter Notebook)


## 🎯 Learning Outcomes

Through these practical assignments, the following concepts are explored using Python:

- Understanding process creation and process management using `os.fork()`, `os.exec*()` and `os.wait()`.
- Implementing multithreading and synchronization using Python's `threading` module.
- Comparing different CPU scheduling algorithms (FCFS, SJF, Priority and Round Robin).
- Solving classical synchronization problems (Producer-Consumer, Readers-Writers, Dining Philosophers) using semaphores.
- Understanding deadlock and avoiding it using the Banker's Algorithm.
- Implementing memory allocation strategies (First Fit, Best Fit and Worst Fit).
- Comparing page replacement algorithms (FIFO, LRU and Optimal).
- Understanding disk scheduling techniques (FCFS, SSTF, SCAN and C-SCAN).
- Exploring file allocation methods (Contiguous, Linked and Indexed).
